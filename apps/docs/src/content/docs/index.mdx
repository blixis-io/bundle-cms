---
title: Blixis CMS
description: An API-first CMS bundle built on Blixis Framework.
---

Blixis CMS is a set of versioned packages. A generated project contains your app entry point, configuration, Compose file, and migration command. Its CMS runtime comes from `@blixis-io/cms-api`.

The API-only walking skeleton serves `/health`, `/openapi.json`, and `/api/v1/auth/me`. The last route requires the administrator API key created during scaffolding. These paths and responses are checked by the packed-tarball smoke test in `tooling/smoke/packed.mjs`.

See [Create an API](/start/create-api/) for the first-run workflow.
